# Three-minute demonstration plan

Only claim live NVIDIA generation after it has actually been configured and verified. If not, show the local reference path explicitly and state that the integration is pending; do not splice in a fake API success.

- **0:00–0:20 — Imagine.** Open the cinematic prompt console. Describe a small warehouse rover. Point out that the model is NVIDIA Nemotron hosted through Nebius Token Factory. Show the actual selected catalog model and local request usage, without exposing credentials.
- **0:20–0:50 — Construct.** Show the validated component specification turning into a procedural 3D machine in dependency order. Orbit, explode, isolate a motor, and replay assembly.
- **0:50–1:15 — Understand.** Select the camera and motor controller. Explain their distinct roles with actual component relationships. Ask one grounded tutor question if live inference is verified.
- **1:15–1:45 — Compute.** Assign a perception task, then set explicit memory and deadline assumptions. Compare CPU and Jetson candidates. Explain that memory/power suitability is a heuristic and no inference latency benchmark has been measured. Change to a non-vision task and show why a GPU is not always needed.
- **1:45–2:20 — Test.** Run the real flat-floor drive experiment on a supported rover. Show solver time, displacement, trajectory, contacts, joint states, and actuator forces. Explain that this tests drive dynamics, not warehouse navigation or the selected GPU.
- **2:20–2:45 — Learn.** Generate a contextual quiz/card if live AI is verified. Record an attempt; show the notebook and persistent experiment. Cloud sync is shown only if Supabase is actually configured and tested.
- **2:45–3:00 — Improve.** End with measured evidence, explicit limitations, and the next experimental modification. Briefly distinguish this working slice from future Isaac Sim and robot-learning work.

Keep API keys, account billing details, personal email, access tokens, and terminal environments out of the recording. No fabricated simulation trajectories, cloud deployment claims, GPU speedups, or availability assertions.
